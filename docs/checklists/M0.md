# M0 in-game check: running the probe

The probe `AzPr_Probe` is a throwaway development addon. It only listens and asks: it never trades, casts, accepts or buys anything for you. This checklist is what you do in the real WoW Forever client to answer the checks **V1-V21** and **L** (content levels). Nothing here has been run in the game yet.

You do not need to read any code. Each check links to its entry in the [spike README](../spike/README.md), which says what counts as a pass, if you are curious.

**You do not have to do everything.** Run what you can; a run you skip simply stays `todo`, and that is a useful answer too. Say which runs you skipped in the report.

## Warnings: read these first

- **Test messages are capped.** A burst sends at most 50 messages, a session at most 400 until `/reload`. Do not try to get around the cap. `/azpp burst stop` ends a burst early.
- **Change no CVar** (no `/console` command) except exactly as [run 10](#run-10-restriction-cvars-v16) says: one at a time, and set it back right after. Switching nameplates on in the game's *Options* menu is fine.
- **Before you paste anything**, replace player, guild and realm names with placeholders such as `PlayerA`, `GuildA`, `RealmA` (also account names). The probe is built not to write names, but look anyway, in the export and in your own text, and in screenshots if you attach any.
- **Hardcore:** a death is permanent. Use only a throwaway low-level character, and only if you choose to.
- If a Lua error appears, or a "blocked action" popup, copy it (names replaced) and note what you were doing.

## What you need

- WoW Forever, on an **English client** if possible (a second, short pass on an Italian client helps runs 3, 4, 5 and 6).
- For the group, message, duel and trade runs: a **second player or a second client**, also running the probe. Call yours **A** and the other **B**.
- If you can: a character of the **opposite faction** on the same realm, a player **10 or more levels above** yours, a raid group, a Hardcore character, a trial account.
- Python 3 on your computer, for the installer (or copy the folder by hand).

## Install

With the script, from the repository folder:

1. Copy `tools/local.example.ini` to `tools/local.ini` (never committed) and set `addons` to your folder `<WoW folder>/_forever_/Interface/AddOns`.
2. Run:

```powershell
python -I -X utf8 tools/install_probe.py
```

By hand instead: copy the whole folder `tools/probe/AzPr_Probe` into `<WoW folder>/_forever_/Interface/AddOns`, so that `AzPr_Probe.toc` is at `<WoW folder>/_forever_/Interface/AddOns/AzPr_Probe/AzPr_Probe.toc`.

Then, on every client:

3. Start the game (or `/reload`). If it says the addon is out of date, enable **Load out of date AddOns** and note it in the report.
4. The chat shows `loaded (development only)`. Type `/azpp list`: it lists 22 checks (V1-V21 and L), each with the contexts it still misses. **If it does not, stop and report that**: it is the first result.
5. After every update of the probe, install it again and `/reload`. Your results are kept.

## How the commands work

| Command | What it does |
|---|---|
| `/azpp list` | The checks, what is still missing, the last result |
| `/azpp run V3` | Runs one check now, where you are (use any id: `V1` … `V21`, `L`) |
| `/azpp export` | All results and logs as text, already selected: Ctrl+C |
| `/azpp help` | All commands |
| `/azpp reset` | Erases everything (only after `/azpp reset confirm`). **You never need it** between runs |

A result is `pass`, `fail`, `info` or `todo`. `todo` lists what is missing; `fail` is a finding, not your mistake. Context names in those lists: **W** open world out of combat, **WC** open world in combat, **D** dungeon, **DB** dungeon boss fight, **R** / **RB** raid / raid boss, **BG** battleground, **2C** second player, **2CX** second player of the other faction, **HC** Hardcore, **LS** crossing a loading screen.

The probe records most events by itself, so you can just play; the commands add a reading of the current situation. `/azpp run` during a fight is fine.

## The runs

Do them in this order. They share characters, so one evening can cover several. After each long run, an `/azpp export` is a cheap backup.

### Run 1: open world, alone

Checks: V2, V3, V6, V7, V9, V12, V13, V14, V15 (part), V19-V21 (baseline), L.

1. In the game's *Options*, switch **friendly and enemy nameplates** on.
2. In a city and near enemies: look at the nameplates (you should see a small test icon above them), point at and target players (the tooltip should have the line `AzPr Probe: tooltip line`), and watch chat (other players' lines should start with a question-mark icon).
3. Right-click another player's portrait or name: the menu has **AzPr Probe: menu entry**. Click it (it prints `probe menu entry`). Open the menu again and within 30 seconds click **Whisper**, then **Invite**, then (out of combat) **Set Focus**. Note whether each works.
4. Out of combat: `/azpp run V2`, `/azpp run V3`, `/azpp run V12`, `/azpp run V13`, `/azpp run V14`. Then pull a mob and repeat `/azpp run V2`, `/azpp run V3`, `/azpp run V14`. While still fighting, hover a player (tooltip) and say something in chat, with another player around if you can.
5. If something misbehaves, switch one surface off to find which: `/azpp surfaces plates off` (or `tooltip`, `menu`, `chat`, `all`), later `on`.
6. **Quests:** accept a quest and turn it in, alone (and again in a group later); a daily or repeatable one too if there is one. Then `/azpp run V6` and `/azpp run L`.
7. **Legacy:** out of combat `/azpp run V7`. Just before you earn a Legacy (exploration or quest), type `/azpp legacy watch 120`, earn it, and `/azpp run V7` again.
8. **Exploration:** with a low-level character, walk into new sub-zones, then `/azpp run V9`.
9. If a higher-level player or a stranger buffs you, do it out of combat and in combat, then `/azpp run V20`.

### Run 2: professions, flight master and city NPCs

Checks: V9, V10, V15.

1. **NPCs:** open and close, one at a time: a gossip NPC, a quest giver, a vendor, a trainer, the bank, the auctioneer, a mailbox, a flight master, an innkeeper.
2. **Windows:** open character, spellbook, quest log and professions; `/azpp run V15` with them open, then again with all closed.
3. **Flight:** open the flight master, learn a new node if you can, open the map again, then `/azpp run V9`. Type `/azpp uiwatch flight`, take a flight of at least 30 seconds, and `/azpp uiwatch stop` on arrival.
4. **Boat and zeppelin:** `/azpp uiwatch boat` before boarding, stay aboard and **stand still** for the crossing, `/azpp uiwatch stop` on arrival. Same with `/azpp uiwatch zeppelin`.
5. **Cinematic, loading screen, death:** watch a cinematic (a new character's intro, for example), enter and leave an instance, die once. Then `/azpp run V15`.
6. **Professions:** at a trainer learn a recipe; open the profession window (one primary and one secondary profession); gather until a skill-up; craft something; close the window; `/azpp run V10`.

### Run 3: auction, mail and trade

Checks: V11 (needs player B for trades).

1. Open the auctioneer and put a cheap item up for sale. If there is **no Auction House**, write that in the report.
2. When it sells, open the mailbox and `/azpp run V11`. If the result says the invoice is empty, open that mail by hand and run it again.
3. With B: one trade (item for gold) that you **complete**, then a second one that you **cancel**. Then `/azpp run V11`.

### Run 4: group with a player 10+ levels higher, duels and honour

Checks: V8, V19, V20, V21. Needs B, ideally 10 or more levels above A.

1. Form a party with B. Run `/azpp run V19` with B near you, then with B in another zone, then with B logged out.
2. With B buffing or healing you while **not** in your party, in and out of combat: `/azpp run V20`.
3. With B outside your party: type `/azpp assist 120`, then pull a mob while B attacks your target; in a second fight let the mob attack B. Then `/azpp run V21`. `/azpp assist stop` ends the window early.
4. If you are on a PvP realm, stand near a hostile player far above your level (target or nameplate), `/azpp run V19`, and make an honourable kill.
5. Duel B twice, one win and one loss, then `/azpp run V8`.

### Run 5: dungeon, with bosses

Checks: V1, V2, V3, V6, V9, V12, V13, V19, V20, V21, L. In a party if possible, with characters at the dungeon's level.

1. Enter (that is the loading screen). Out of combat: `/azpp run V2`, `/azpp run V3`, `/azpp run V9`, `/azpp run V12`, `/azpp run V13`, `/azpp run V19`, `/azpp run V20`, `/azpp run V21`.
2. Kill at least one boss, and keep a wipe if one happens. During a boss, say something in party chat and run `/azpp run V2`, `/azpp run V3`, `/azpp run V20` (best with a party member's buff on you). V1 and L record by themselves; each pull prints a chat line.
3. **Once during a boss**, `/reload` or relog if the group agrees, to see whether the encounter survives it.
4. Turn in a dungeon quest if you have one. With B in the party, send one `/azpp ping party` from inside (use `instance` if the group was formed by the game's group finder). At the end: `/azpp run V1`, `/azpp run V6`, `/azpp run L`. Leave the instance.

### Run 6: raid, if you can

Checks: V1, V2, V3, V5, V19, L.

Do the same as run 5 (steps 1 and 2): at least one boss kill, `/azpp run V2`, `/azpp run V3`, `/azpp run V19` out of combat, then `/azpp run V1` and `/azpp run L`. Barrow Deeps is the smallest raid.

### Run 7: battleground

Checks: V2, V3, V5, V8, V12, V13, V18, V19. Darkspear Islands; two matches (one won, one lost) are ideal.

1. During the match: `/azpp run V2`, `/azpp run V3`, `/azpp run V12`, `/azpp run V13`, `/azpp run V19`, `/azpp run V18`; hover players and use the unit menu once, and say something in chat. With B in your group, send one `/azpp ping instance` from A (this covers V4 in a battleground).
2. **Stay until the end screen**, then `/azpp run V8`.

### Run 8: two clients, messages

Checks: V4, V5, V14. A sends, B receives; both run the same probe version. Same faction, same guild and same party for steps 1-6. Replace `<B>` with B's character name (it is not stored).

1. Both: `/azpp channel join`. No "Joined Channel" line should appear. Then `/azpp channel status` (should report 0 chat frames) and `/azpp channel count`.
2. A: `/azpp ping guild`, `/azpp ping party`, `/azpp ping whisper <B>`, `/azpp ping channel`. One reply line per ping should show up.
3. A: `/azpp size guild`, then `/azpp size whisper <B>`, then `/azpp size channel`.
4. A, for each of `guild`, `party`, `whisper <B>`, `channel` (and `raid` in a raid): `/azpp burst <dist> 10 0`, then `/azpp burst <dist> 20 0.5`, then `/azpp burst <dist> 30 1`. Wait **15 seconds** between bursts; `/reload` between two destinations resets the 400 cap.
5. Both: `/azpp run V14` in the open world and again in combat. A: `/azpp encsend whisper <B>` and `/azpp encsend channel`; A should print `encoded profile acknowledged: ok`.
6. Both: `/azpp lockdown auto on`. Then `/azpp lockdown` in the open world, again in combat, in a dungeon (out of combat and during a boss), in a raid and during its boss, and in a battleground, with A and B in the same group (combine with runs 5-7). Leave and enter an instance once.
7. At the end, both: `/azpp run V4`, `/azpp run V5`, `/azpp run V14`, then `/azpp export` (label the two A and B). Then `/azpp channel leave` and `/azpp lockdown auto off`.

`/azpp msgs` shows the counters at any time; `/azpp pong off` stops automatic replies (they are on by default).

### Run 9: opposite faction and trial account

Checks: V4.

1. B is on the **opposite faction**, same realm; both `/azpp channel join`. A: `/azpp ping channel`, `/azpp burst channel 10 1`, `/azpp encsend channel`. Then B does the same towards A. Both export.
2. **Trial account, if you have one:** on it, `/azpp run V4`, `/azpp ping guild` (or `party`) and `/azpp ping whisper <B>`; export from both clients. Both `/azpp channel leave` at the end.

### Run 10: restriction CVars (V16)

Only here, in a safe place, **out of combat**, open world.

1. Target a friendly NPC and keep **the same target** throughout. `/azpp run V16`: it prints `/console` commands.
2. Type **one** `/console <name> 1` command it printed, then `/azpp run V16`.
3. Type the printed command that **sets it back**, then `/azpp run V16` again.
4. Repeat steps 2-3 for each name, one at a time. Never leave one changed. If something does not come back to normal, set it back, restart the game and report it.

(`/azpp cvar` prints the commands again; `/azpp cvar <name>` adds another name to test, only if someone gave you one.)

### Run 11: Hardcore (V17)

1. On a **normal** realm character: `/azpp hardcore no`, then `/azpp run V17`.
2. On a **throwaway** low-level Hardcore character: after logging in, `/azpp hardcore yes` and `/azpp run V17` (type `hardcore yes` again after every login or `/reload`). A hunter: use Feign Death once.
3. The death is your choice. After it, `/azpp run V17` if the game still lets you; if the character can log in again, do so and run it again.
4. Export after your last character.

## Export and report

1. On the character you finished with, `/azpp list`, then `/azpp export`. A window opens with the text selected: press **Ctrl+C** and paste it into a text file. Results are shared by all characters of one account; each other account or client needs its own export.
2. **Replace player, guild, realm and account names** with placeholders.
3. On GitHub, open a new issue with the **In-game test report** form. In *Check* write the ids (for example `M0 probe, V1-V21 and L`); in *Game client* the build from the first line of the export, and your language; choose the result that fits best; in *What you did and what you saw* list the runs done and skipped, errors, popups and anything odd (steps that need your eyes: icons on plates, the tooltip line, the chat icon, the menu entry, "Joined Channel" lines, no Auction House); paste the export in the last box.
4. If the text is too long for the form, attach it as a `.txt` file in a comment (names already replaced) or split it over several comments.
5. When you are done testing, you can delete the `AzPr_Probe` folder.
