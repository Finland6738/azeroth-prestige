# In-game checklists

What only the real WoW Forever client can confirm. Every milestone ends with its checklist (`M<N>.md`), written by its second-to-last step so that the owner can run it alone, without reading the code; `release.md` merges every open check before `v1.0.0` ([roadmap](../roadmap/README.md)).

Report each result with the *In-game test report* issue form, using the check's id (for example `V3` or `M2 step 4`), and paste the `/azp debug` report (or the probe export during M0). Replace player, guild and account names with placeholders.

| Checklist | Milestone | Status |
|---|---|---|
| `M0.md` | the probe: checks V1-V21 | written in step M0.8 |
| `M1.md` … `M7.md` | one per milestone | written in the checklist step of each milestone |
| `release.md` | everything still open, before `v1.0.0` | written in step M7.9 |
